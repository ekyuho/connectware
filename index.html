01 / SMART HEATING

Valve God밸브의 신

더운 방과 추운 방, 충분히 쓰지 못한 난방 열.
지역난방 아파트의 불편을 직접 해결했습니다.

온도 센서와 난방 밸브를 연결해 방별 난방을 제어하는 시스템을 직접 제작했습니다. 지역난방으로 공급받은 열을 충분히 활용하고, 방마다 다른 난방 편차를 줄이기 위한 프로젝트입니다.

실제 가정에 적용해 온도 변화를 관찰하고 제어 방식을 조정했습니다. 2015년 발표자료에는 난방 쏠림을 해결하고 열 활용을 개선한 제작·운영 경험을 담았습니다.

이후 서울시립 북서울미술관의 《메이크 잇 Make it》전에 초대되었습니다. 메이커 운동을 현대미술의 관점에서 재해석한 이 전시에서, 생활의 문제를 스스로 해결하는 만들기가 예술과 만나는 사례로 소개되었습니다.

방별 난방 제어열에너지 활용생활 속 IoT
Valve God 최초 공개 자료 ↗일상의 실험에서, 만들기의 문화로.

02 / FULL STACK DEVELOPMENT

디지털 미술펜Digital Art Pen

센서에서 앱, 서비스까지.
스타트업의 아이디어를 실제 시스템으로 만들었습니다.

태블릿 펜에 모션 센서를 붙여 데이터를 수집하고 행동을 분석하는 스타트업을 위해 진행한 프로젝트입니다. AI의 등장은 다양한 기술과 도구에 대한 문턱을 대폭 낮추어 줍니다. 본 프로젝트는 nRF52840을 CPU로 사용하고, 42688 6축 IMU를 사용합니다. PCB 제작부터 Android 앱 개발, 서비스 웹 구축까지 풀스택으로 구현하였습니다.

현재 어르신들의 치매 관련 행동 분석에 1차적으로 활용되고 있습니다.

PCB 제작Android 앱서비스 웹

03 / MOBILE SENSING

부산 버스
모바일 센서 시스템Busan Bus Mobile Sensor System

달리는 버스에서 수집한 데이터.
현장에서 설치하고, 장기간 모니터링했습니다.

부산의 여러 노선버스에 실내·실외 센서 60세트를 부착하고, 1년여간 데이터를 모니터링한 프로젝트입니다. 실제 운행 환경에서 센서 시스템을 설치하고 운영한 경험을 담고 있습니다.

센서 60세트실내·실외 센싱1년여 모니터링

2017.10.24—12.25 / EXHIBITION

메이크 잇 Make it

제4차 산업혁명의 흐름 속에서 주목받은 메이커와 메이커 운동을 현대미술의 관점에서 재해석한 전시입니다. Valve God은 이 전시에 초대되어, 일상의 문제를 직접 해결하는 제작 사례로 소개되었습니다.

전시는 대안적 자립과 기존 기술을 분석해 다시 만드는 실천을 통해 비판적 제작의 방법과 대상을 탐구했습니다. 경제적 성과와 취미의 범위를 넘어, 만들기의 지속가능성과 공예를 통한 사회적 실천인 크라프티비즘의 가능성을 조명했습니다.
